# Microwave-Man!

**Microwave Man** is a free and open-source 2D platformer, made in [Godot](https://godotengine.org/). This was [Titled Games](https://titledgames.project516.dev)' submission for [Game Off 2025](https://itch.io/jam/game-off-2025).


## Playing the Game

The easiest way to play is to download the pre-built game from the [Releases](https://github.com/TitledGames/Microwave-Man/releases) page. 

Alternatively, install from Flathub if you're on Linux:

<a href='https://flathub.org/apps/dev.project516.titledgames.microwave-man'><img width='180' alt='Download on Flathub' src='https://dl.flathub.org/assets/badges/flathub-badge-en.png'/></a>

We have an *experimental* [web build](https://titledgames.project516.dev) available too. It has many issues, like screensize, so prefer the desktop builds for the best experience!
